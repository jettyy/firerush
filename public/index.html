1. 네이버 로그인

세션은 이 컴퓨터에만 저장됩니다.

로그인 버튼을 누르면 실제 브라우저 창이 뜹니다. 아이디·비밀번호는 그 창에 직접 입력하세요. 이 프로그램은 로그인 정보를 저장하거나 전송하지 않습니다.

2. 주제 붙여넣기

0개 인식

주제에 TOP100, 50가지, 베스트 30 처럼 개수가 들어 있으면 그 개수만큼 표를 채웁니다. 개수 없이 "~~~ 순위" 라고만 써도 100개를 목표로 최대한 많이 채웁니다. (설정에서 조절) 뒤쪽 구간에서는 지방·소규모·전문 분야까지 넓혀서 찾습니다. 자료가 모자라면 확인되는 데까지만 넣고, 빈 행을 지어내지는 않습니다. (25개씩 나눠 생성하므로 시간이 꽤 걸립니다)

3. AI에게 줄 지침 & 참고 예시

여기 쓴 내용이 가장 먼저, 가장 강하게 적용됩니다

입력 후 자동으로 저장됩니다. 여기 쓴 내용은 프롬프트 맨 앞과 맨 끝에 두 번 들어가고, 기본 규칙과 충돌하면 이 지침이 이깁니다.

참고 예시 글

0개

"이런 식으로 써줘" 하고 보여줄 글을 올리면 문체와 구성을 참고합니다. txt / md / html / csv 파일을 올리거나 아래에 직접 붙여넣으세요. (내용을 베끼지는 않습니다)

    4. 설정

    이미지 생성은 상단 썸네일의 배경 그림 한 장에만 씁니다. 한글 문구는 프로그램이 그 위에 얹으므로 글자가 깨지지 않고, 본문 강조 카드 3장은 지금처럼 공짜로 만듭니다. 키를 저장한 뒤 이미지 API 테스트를 눌러 한 장 뽑아보세요. 글 100편에 대략 7천원선이고, 모델 이름과 가격은 구글이 자주 바꿉니다.

    주제를 100개 돌리기 전에 연결 테스트를 한 번 눌러보세요. 모델을 쓸 수 없거나 로그인이 풀렸으면 여기서 바로 드러납니다.
